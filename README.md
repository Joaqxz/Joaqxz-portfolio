# 💼 Joaquim Almeida — Portfolio

Personal portfolio website built with Angular to showcase my projects, skills, and journey in software development.

This project serves as a central place to showcase my work and experience in software development, including web applications, systems, automation and APIs.

The goal is to present my skills in an organized and professional way while making it easy to explore the projects I build.

## 📦 Getting Started

### Prerequisites

* Node.js installed
* Angular CLI installed

### Installation

Clone the repository:

```bash
git clone https://github.com/Joaqxz/Joaqxz-portfolio.git
```

Navigate to the project directory:

```bash
cd Joaqxz-portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
ng serve
```

Then open your browser and visit:

```text
http://localhost:4200/
```
